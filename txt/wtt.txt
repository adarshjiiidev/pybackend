# WTT (Weak Towards Top) - Complete Guide

## Definition

**WTT = Weak Towards Top**

**Technical:** Second highest OI/Volume is ≥75% of the highest, located at TOP side (larger strike prices) near imaginary line

**Simple:** When market shows weakness toward top/head side

## The 75% Rule

**Formula:**
```
If Support/Resistance = 100% (highest value)
Then WTT must be ≥75% at TOP side
```

**Example:**
```
Resistance at 17500: 10 Lakh OI (100%)
Strike at 17550: 8 Lakh OI (80% of 10L)
                  ↑
            This is ≥75%, so WTT exists!
            
WTT confirmed at 17550
```

### WTT Market Pressure Rules

### Core Rules (CRITICAL):

**1. WTT to Strong = BEARISH Pressure** ✓
```
Yesterday: WTT (weak toward top)
Today: Becomes STRONG (second highest <75%)
= Market turned BEARISH
```
*Why?* The potential to go UP (WTT) failed. The Bullish pressure vanished. So Bears take control (Bearish).

**2. WTT se Strong = BEARISH Pressure** ✓
```
Current: Shows WTT (Bulllish potential)
Then: Becomes Strong (Bullish potential dies)
= BEARISH momentum
```

**3. Shifting on WTT = BULLISH Pressure**
```
Market shifts TO a WTT level
= BULLISH signal (Market moved UP to the new level)
```

**4. Support WTT = BULLISH Potential (initially)**
```
Support usually WTT means it wants to shift up (Bullish).
BUT if it FAILS to shift and becomes STRONG -> BEARISH.
```

**5. Resistance WTT = BULLISH Presure**
```
Resistance WTT means it wants to shift up (Bullish).
If it shifts -> Bull Run possibilities.
```

## WTT Shifting Scenarios

### Scenario A: Shift to WTT Level & Again WTT = Bull Run

```
Step 1: Resistance at 17500 (strong)
Step 2: Resistance SHIFTS to 17550 (WTT level)
Step 3: At 17550, it shows WTT again (at 17600)

Result: BULL RUN (strong bullish)

Why: Market shifted UP and wants to go UP AGAIN = major uptrend
```

### Scenario B: WTT to Strong = BEARISH (CRITICAL RULE)

**WARNING:** Do not confuse this! 
- Many think "Strong means market goes up". NO.
- **Resistance Becoming Strong** means "The door to go UP is CLOSED".
- So WTT (Door Open) → Strong (Door Closed) = **BEARISH**.

**Example:**
```
9:15 AM: Resistance at 17500 shows WTT at 17550 (weak toward top)
         17500 - 10L, 17550 - 8L (80%)
         *Potential to go UP is there.*
         
10:00 AM: Same resistance becomes STRONG
          17500 - 12L, 17550 - 6L (50%)
          
Result: BEARISH Pressure

Why: The door to go UP is closed. Resistance became strong. Market falls.
```

## Anti-Hallucination Guide

1. **WTT means "Weak Towards Top"**, NOT "Weakness To Trade". Never use "Weakness To Trade".
2. **Resistance WTT to Strong is NOTICEABLY BEARISH.**
   - Do NOT say it is bullish because "resistance became strong".
   - It is bearish because "The weakness (upward potential) died".
3. **Analogy:**
   - WTT = Door is creaking at the top. (Bullish hope).
   - Strong = Door is reinforced with steel. (Hope dead -> Bearish).

## Game of Percentage with WTT

### WTT Percentage Increasing = BULLISH Pressure

```
Time 1: WTT at 75%
Time 2: WTT at 80%
Time 3: WTT at 85%

= Weakness GROWING toward TOP
= More chance to shift UP
= BULLISH pressure
```

### WTT Percentage Decreasing = BEARISH Pressure

```
Time 1: WTT at 85%
Time 2: WTT at 78%
Time 3: WTT at 70% (no longer WTT!)

= Weakness REDUCING
= Chance to shift UP is dying
= BEARISH pressure
```

## Natural Weakness - Important Exception

**Rule:** If weakness appears exactly where shifting happened FROM, ignore it.

**Example:**
```
Before: Resistance at 17550
After: Resistance SHIFTS to 17500 (Down shift)

Now 17550 shows WTT
= This is NATURAL WEAKNESS (ignore it)

Why: Old resistance level naturally weakens/lingers after shift
```
